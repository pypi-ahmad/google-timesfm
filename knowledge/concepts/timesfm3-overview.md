# Overview

TimesFM-3 is Google Research's TimesFM 3.0 checkpoint for zero-shot univariate
and multivariate forecasting with optional covariates.[^blog]

# Version baseline

Use `v3.0.0` as the released code/weights baseline and current `master` package
version 3.0.1 as the implementation baseline. They are distinct revisions.[^release][^repository]

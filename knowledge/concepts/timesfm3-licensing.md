# License boundary

The repository source is Apache-2.0, but the default TimesFM-3 weights are
under the separate TimesFM Non-Commercial License v1.0.[^repository][^weights-license]

Do not infer commercial or production permission for default weights from the
repository license. Seek a separate commercial license where the weights' terms
require one. This is a factual reference, not legal advice.[^weights-license]
